🏠🤖 hAI.FHEMChatAgent

Dein Zuhause. Dein Assistent. Web-Chat und Telegram-Bot für FHEM – mit KI-Tool-Calling, MCP und Einzelfreigabe für jede Schreibaktion.

GitHub-Repo ↗ Portainer-Stack Build-Verlauf

✨ Features

💬

Web-Chat

Mobile-first, dunkles Home-Studio-Design mit Vorlagenkarten.

✈️

Telegram

Inline-Menü, private Chats, Whitelist per User-ID.

🧠

KI-Tool-Calling

OpenAI-kompatible API, Modell frei wählbar.

🔌

FHEM-MCP

Nur fhem_*-Tools, streamable-http oder SSE.

🔐

Einzelfreigabe

Ein Klick = genau ein Schreibaufruf, mit Ablauf.

🐳

Ein Container

Portainer-Stack, SQLite-Volume, GHCR-Image.

🧭 Architektur

Web-Chat ──┐
           ├─▶ FastAPI ─▶ LLM (Tool Calling)
Telegram ──┘      ├─▶ FHEM-MCP (fhem_*)
                  ├─▶ FHEMWEB (optional)
                  └─▶ SQLite (/data)

🚀 Installation in 5 Schritten

#Schritt
1Erfolgreichen CI-Lauf Test and publish abwarten
2Bei privatem Paket ghcr.io in Portainer als Registry eintragen
3Stack aus portainer-stack.yml anlegen
4APP_PASSWORD, OPENAI_API_KEY, MCP_API_KEY setzen
5Deploy, dann http://SERVER:8088 öffnen
git clone https://github.com/jbkunama1/hAI.FHEMChatAgent.git
cd hAI.FHEMChatAgent
cp .env.example .env
docker compose up -d --build
⚠️ Nicht ungeschützt ins Internet stellen: HTTPS-Reverse-Proxy oder VPN verwenden. Schreibaktionen nur nach Einzelfreigabe. Diese Seite ist nur eine Projektseite; der Agent läuft in deinem eigenen Container.
